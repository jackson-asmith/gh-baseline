# Architecture decision records

Each record captures one decision that has a reasonable alternative, so a
later reader can see what was weighed and why. Records are short and
numbered; a decision that changes gets a new record that supersedes the old
one rather than an edit.

| # | Decision | Status |
|---|---|---|
| [0001](0001-standard-library-only.md) | Standard library only | Accepted |
| [0002](0002-plan-limited-rulesets.md) | Classify plan-limited rulesets in the collector, by message | Accepted, amended |
| [0003](0003-precompiled-releases.md) | Distribute as a precompiled `gh` extension | Accepted |
| [0004](0004-yaml-parser-for-workflows.md) | YAML parser for workflow files | Accepted |

New records copy the sections of an existing one: Context, Decision,
Alternatives considered, Consequences.
